Before you install

These are original documentation examples for Nenyoo GTA V Premium’s native Engine + Foundation API. Place them in %LOCALAPPDATA%\Nenyoo\Plus\Scripts\User\They are native menu-page scripts, so keep the -- @nenyoo-menu marker and use the native user folder rather than User/stand.

Reviewed against the bundled reference and source on 2026-11-13; no in-game testing or build-specific compatibility is claimed. Read each example’s limits before using or adapting it.
