Check your product and edition

This page brings together the setup requirements documented on this website. Game updates, Windows changes and product updates can affect compatibility. A store listing means the product is offered for sale; it is not a live operational status indicator.

Content reviewed: November 13, 2026

Tested game build numbers and a live compatibility feed are not published on this page. Confirm your exact game edition, build number, Nenyoo tier and Windows version with support before purchase or after a game update.

What to include in a compatibility question

  • Game name, edition and exact build number
  • Nenyoo product/tier and loader or menu version, if shown
  • Windows version and the exact error, if there is one
  • For GTA V, whether BattlEye is enabled and which setup steps you completed
