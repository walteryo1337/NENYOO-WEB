About this build

The source title retains the credit “By Barbosa Br”. This JSON scene has 204 recorded attached entities and three original screenshots, making it a distinct alternative to CarMet V1.

The source file is CarMet-Ls_By_Barbosa-Br.json, retained from Vehicles/S512/CarMet-Ls_By_Barbosa-Br/CarMet-Ls_By_Barbosa-Br.json. The model and attachment information above reproduce the catalog metadata; the screenshots show the source presentation.

How to try this vehicle preset

  1. Keep a copy of your current vehicle. Save it in the menu before trying another community preset.
  2. Download the original file. Keep the name CarMet-Ls_By_Barbosa-Br.json and its .json extension. Changing the extension does not convert the file.
  3. Copy it into your saved vehicles folder. Paste this path into File Explorer: %LOCALAPPDATA%\Nenyoo\Plus\Vehicles You can also use Saved Vehicles → Open Folder in the menu.
  4. Open Saved Vehicles. Select the entry named CarMet-Ls_By_Barbosa-Br. Use an open area so there is room for the build and any attached entities.

If the file does not appear, check its folder and extension, then reopen the saved list. If it fails to load, keep the original file and collect the relevant log for support.
