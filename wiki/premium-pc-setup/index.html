Disable Secure Boot and virtualization

Prepare UEFI and Windows settings for Premium, with illustrated motherboard examples and setup checks.

Updated September 23, 2026

Use this checklist when preparing your PC for Premium (BattlEye on). Keep BattlEye enabled in GTA V. These PC settings are separate from the game’s BattlEye setting.

Heads upBefore changing your PC settings

Disabling Secure Boot, Memory Integrity, or virtualization-based security reduces Windows protections. Firmware changes can trigger BitLocker recovery. Save your recovery key before making changes, record your original settings, and follow your PC manufacturer’s instructions. Virtual machines, WSL2, Docker Desktop, and Windows Sandbox may stop working with virtualization disabled.

See Microsoft’s Secure Boot instructions ↗ and Windows device security ↗ for the security implications. If your PC uses BitLocker or Device Encryption, follow BitLocker: suspend, resume, or turn off before changing firmware settings.

Before you start

Read the whole guide before making changes. Save your work, record your original settings, and complete the checks relevant to your PC. These steps are for the Premium loader mode that requires them; they are not general Windows performance tweaks.

  • Secure Boot: Off.
  • Firmware Fast Boot: Disabled. This is separate from Windows Fast Startup.
  • CPU virtualization: Off — Intel VT-x / Virtualization Technology and VT-d, or AMD SVM / AMD-V and IOMMU where available.
  • Windows hypervisor, VBS, and Memory Integrity: not running. Verify after restarting, not just after changing a setting.
  • Boot mode: UEFI. Do not switch an existing Windows installation to Legacy / CSM.
  • BitLocker / Device Encryption: follow the separate BitLocker guide to check encryption, save the recovery key, and choose the appropriate suspend or turn-off steps. Do not clear the TPM.

Check your current settings

  1. 1
    Open System Information

    Press Win + R, enter msinfo32, and press Enter.

  2. 2
    Check Secure Boot State

    If it already says Off, you do not need to change Secure Boot.

  3. 3
    Check virtualization

    Look for Virtualization-based security and, if shown, Hyper-V - Virtualization Enabled in Firmware. For this loader mode, check for Not enabled and No, respectively.

Open your UEFI / BIOS settings

  1. 1
    Restart into firmware settings

    Hold Shift while choosing Power → Restart in Windows. Select Troubleshoot → Advanced options → UEFI Firmware Settings → Restart.

  2. 2
    Use your manufacturer’s setup key if needed

    If UEFI Firmware Settings is unavailable, consult your PC or motherboard manual for its startup setup key. Common keys include F2 and Delete, but they vary by model.

Disable Secure Boot

  1. 1
    Find Secure Boot

    Look under Boot, Security, Authentication, BIOS Features, Advanced, or System Configuration. Some boards require Advanced Mode to show the setting. If a setting is unfamiliar, open a support ticket with a screenshot before changing it.

  2. 2
    Set Secure Boot to Disabled

    Change only the Secure Boot setting. Do not clear Secure Boot keys, reset the TPM, or switch the Windows boot mode to Legacy / CSM.

  3. 3
    Disable firmware Fast Boot

    In the firmware’s Boot settings, set Fast Boot to Disabled if present. This is not the Windows Fast Startup option. Keep the boot mode set to UEFI.

  4. 4
    Save your changes

    Use Save Changes and Exit when finished with the firmware settings. The shortcut is often F10; follow the on-screen prompt.

Disable firmware virtualization

In UEFI / BIOS, look under Advanced → CPU Configuration, CPU Features, or Virtualization Support. Setting names and locations vary by manufacturer.

  • Intel: this setup requires Intel Virtualization Technology / VT-x and VT-d to be disabled.
  • AMD: this setup requires SVM Mode / AMD-V and IOMMU to be disabled.
  • Save your changes and restart Windows. Leave TPM / fTPM settings unchanged.

Motherboard examples with pictures

Choose the example closest to your board: ASUS, MSI, Gigabyte / AORUS, ASRock, or HP OMEN. Expand a picture and select it to enlarge. Yellow outlines show the controls; follow the Set this value, since some reference images show Enabled or Auto. Firmware layouts vary by model and version.

Check Memory Integrity and VBS

Open Windows Security → Device security → Core isolation details and check Memory Integrity. For this setup it needs to be Off. Restart after changing it, then verify that VBS is not running.

If the loader shows Hypervisor / VBS is running, follow the separate Hypervisor / VBS is running troubleshooting guide for Windows settings, the diagnostic download, and support-report instructions.

Final check after restarting

  • In msinfo32, check Secure Boot State: Off and BIOS Mode: UEFI.
  • Confirm firmware Fast Boot and the relevant CPU virtualization controls are off.
  • Confirm Memory Integrity: Off and that WMI does not report VBS / HVCI running. If msinfo32 still says Virtualization-based security: Running, send the diagnostic report to support.
  • If you suspended BitLocker, follow Resume protection after completing the changes.

Return to Premium setup

Return to Launch and inject in GTA V, select Premium (BattlEye on), and follow the loader’s prompts. If the loader requests a reboot, complete it before continuing.

Windows logo, boot hang, or blue screen

Seeing the Windows logo, a boot hang, or a blue screen does not automatically mean you configured the PC incorrectly. Firmware, driver, or Windows compatibility problems can also cause startup failures. Do not keep changing unrelated settings to try to force it to work.

  • For a blue screen, photograph the exact stop code and note whether it happened before or after the Nenyoo boot screen.
  • For a hang, record the last screen shown and when it stops progressing.
  • Include your PC / motherboard model, BIOS version, and the setup steps you completed. Attach bootloader.log and loader.stages.log if available.
  • Open a Discord support ticket for repeated failures or suspected compatibility issues. If Windows cannot start, use device-specific recovery guidance or contact support before making more firmware changes.

Follow Collect logs and report a bug for log locations and a report form. Never include a BitLocker recovery key, license key, or password in your report.

Restore your settings later

Restore your recorded firmware and Windows Security settings using the same screens. If you also changed Windows hypervisor or VBS settings, follow Restore your settings. Restart Windows after restoring settings.
