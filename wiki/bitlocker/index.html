BitLocker: suspend, resume, or turn off

Check drive encryption, save your recovery key, and suspend protection or turn encryption off before setup changes.

Updated September 23, 2026

Use this guide if BitLocker or Device Encryption is enabled while preparing your PC. Suspending protection keeps the drive encrypted but temporarily pauses boot protection. Turning BitLocker off decrypts the drive. Choose the action you need; these are different operations.

Heads upSave your recovery key first

Back up the 48-digit recovery key somewhere you can access without this PC, and keep important files backed up. Do not post the key in Discord. On a work or school device, ask your administrator before changing encryption. Suspending or turning protection off reduces protection against offline access.

Check whether encryption is enabled

  1. 1
    Open an administrator terminal

    Open Start, search for PowerShell or Terminal, right-click it, and choose Run as administrator.

  2. 2
    Check your Windows drive

    Run the status command below. These examples use C:; replace it with your actual Windows drive letter if different.

Check encryption and protection status
manage-bde -status C:

Check Conversion Status, Percentage Encrypted, and Protection Status. Fully Decrypted / 0% means the drive is not encrypted. Fully Encrypted / Protection Off means it is still encrypted with protection off; it is not the same as decrypted. If the command cannot report the status, include its error in a private support ticket.

Suspend BitLocker for boot-setting changes

For temporary BIOS / UEFI or Secure Boot changes, suspension can avoid unnecessary decryption. Save your recovery key, then choose Suspend protection next to the Windows drive in Manage BitLocker, or use this administrator command:

Suspend until the next Windows restart
manage-bde -protectors -disable C:

Without a reboot-count option, Windows normally resumes protection after the next restart. Complete the planned firmware changes and check the status after Windows starts. Firmware changes can still require recovery on some devices, so keep the recovery key available.

If your documented setup requires several restarts, the command below keeps protection suspended until you explicitly resume it. Use it only for the required setup period.

Multiple-restart setup — manual resume required
manage-bde -protectors -disable C: -rebootcount 0

Resume BitLocker protection

After completing the boot-setting changes and confirming Windows starts, select Resume protection in Manage BitLocker, or run:

Resume protection on the encrypted Windows drive
manage-bde -protectors -enable C:

Run manage-bde -status C: again and check Protection Status: Protection On. These protector commands suspend and resume protection; they do not decrypt a drive or re-encrypt a drive that was fully decrypted.

Turn off BitLocker and decrypt the drive

Use this option only if you intend to remove drive encryption. It is a separate choice from temporary suspension. Keep the PC on power and allow decryption to complete.

  1. 1
    Open Manage BitLocker

    Search Start for Manage BitLocker and open it as an administrator. On the Windows drive, choose Turn off BitLocker.

  2. 2
    Confirm decryption

    Read the confirmation and choose to turn it off. Wait for decryption to finish; closing the settings window does not mean it has finished.

  3. 3
    Verify completion

    Run the status command again and check Conversion Status: Fully Decrypted and Percentage Encrypted: 0%.

Administrator terminal alternative — starts drive decryption
manage-bde -off C:
Heads upThis command starts decryption immediately

The terminal command does not show the same confirmation wizard as Control Panel. Protection Off alone does not prove decryption is finished. Check Conversion Status and Percentage Encrypted.

Windows Device Encryption

Some PCs, including supported Windows Home devices, use Device Encryption instead of the full Manage BitLocker interface. In Windows 11, open Settings → Privacy & security → Device encryption. In Windows 10, look under Settings → Update & Security → Device encryption. If available, turn Device encryption off, confirm the change, and wait for decryption. If the setting is missing or managed, ask your device administrator or manufacturer.

Recovery screen or missing recovery key

A BitLocker recovery prompt is asking for the drive’s recovery key, not your Windows password or Nenyoo license. Retrieve it from your saved backup, the Microsoft account used to set up the device, or your work / school administrator. Nenyoo support cannot retrieve or bypass that key. Do not clear the TPM or format the drive as a troubleshooting shortcut.

After setup

If you suspended protection, resume it using the steps above. If you fully decrypted the drive and later want encryption again, use Turn on BitLocker or Device encryption: On and save the recovery key from that setup. Check the resulting status. Return to Secure Boot and virtualization setup when ready.
