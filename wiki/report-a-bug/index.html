Bug reports & support

Collect logs and report a bug

Find the right logs, write clear reproduction steps, and submit a report in Discord #bugs.

Updated September 23, 2026

A useful bug report shows exactly what failed and how to reproduce it. Collect the files from the session where the problem happened, then post one report per issue in the Nenyoo Discord #bugs forum ↗.

Reproduce and record the problem

  1. 1
    Note your setup

    Include your product and tier, GTA V Legacy or Enhanced, game version, and whether BattlEye is on or off. You can optionally include your Windows version. For boot problems, include your motherboard or PC model and BIOS version.

  2. 2
    Write the steps in order

    Start from opening the loader. List each action needed to trigger the issue: product selected, when you clicked Load, game mode or session, and the feature you used. Mention any Lua scripts, ASI plugins, or other mods involved.

  3. 3
    Describe expected and actual results

    Explain what should happen, then what actually happens. Include the exact error message, when it occurs, and whether it happens every time or only sometimes.

  4. 4
    Capture evidence

    Take a screenshot or short recording of the error when possible. See Capture a screenshot or recording. Note the approximate time of the failure so staff can match it to the logs.

Find and collect your logs

Press Win + R, paste the relevant folder path below, and press Enter. Copy the logs to a separate folder after the failure and before retrying repeatedly or resetting your cache. Attach the actual files rather than screenshots of their contents.

GTA V menu logs
%LOCALAPPDATA%\Nenyoo\Plus

Attach nenyoo.log. If present, include nenyoo.prev.log when the failure was in the previous session. If the menu never started, its log may be missing or from an older session; say so and include the loader logs instead.

Loader stage log
%LOCALAPPDATA%\Nenyoo\Loader

Attach loader.stages.log if present, especially for loading or injection failures.

Premium boot log: bootloader.log
%LOCALAPPDATA%\Nenyoo\bootloader

For Premium boot or reboot problems, include bootloader.log if present. A log is not guaranteed to exist if the failure happened before logging started. Do not create an empty replacement; explain which file is missing.

For a Hypervisor / VBS is running warning, run the VBS diagnostic tool and include Nenyoo-vbs-check.txt in your support ticket. The guide explains where the report is saved and how to read it.

Heads upCheck attachments before posting

Do not post passwords, license keys, recovery keys, or account tokens. Check screenshots for personal details and logs for sensitive values. If an attachment contains private information, open a support ticket through Support instead of posting it publicly.

Collect Windows Event Viewer details

For a game crash or freeze, Event Viewer may contain an Application Error or Application Hang from the same time. Collect this alongside your Nenyoo logs. An unrelated error does not explain the crash, and a missing event does not mean the failure did not happen.

  1. 1
    Open Event Viewer

    Press Win + R, type eventvwr.msc, and press Enter. Expand Windows Logs in the left sidebar.

  2. 2
    Open Application

    Select Application under Windows Logs. Wait for the event list to load.

  3. 3
    Open the filter

    Click Filter Current Log… in the right Actions pane.

  4. 4
    Set the event levels

    Leave Logged set to Any time. Check Critical, Warning, and Error; leave Verbose and Information unchecked, as shown below. Click OK.

The filter summary above the results should now show Critical, Error, Warning. Use Date and Time to find entries around the failure, then look for Application Error or Application Hang in the Source column. The list can include unrelated warnings; check the application named in each event before sending it.

  1. 1
    Find the matching error

    Look for an event at the time the game crashed or stopped responding. Double-click it to open Event Properties. Check the General tab for the affected application, such as GTA5.exe; avoid collecting an unrelated application’s error.

  2. 2
    Copy the event details

    Click Copy at the bottom of Event Properties and paste the details into your Discord ticket. Include the event source, Event ID, application name, and any faulting module or exception code shown. Review the copied text for private information before sending.

If staff ask for the original event file, close Event Properties, select the matching event, and choose Save Selected Events… in the Actions pane. Save it as an .evtx file and attach it to your private ticket. For a reboot or blue screen, staff may also ask for events from Windows Logs → System.

Submit the report in Discord

  1. 1
    Open the bugs forum

    Join Nenyoo Discord ↗, then open #bugs ↗. Check for an existing report about the same issue first.

  2. 2
    Create a clear report

    Use a title such as GTA V Enhanced — crash after clicking Load. Follow the forum’s current posting instructions and tags, then fill in the report form below and use Copy report for Discord. Paste the generated report into your forum post.

  3. 3
    Attach the evidence

    After pasting the report text, use Discord’s + / Upload a File button or drag the relevant logs and screenshots into the post before sending. The website’s copy button does not attach files. Include bootloader.log for Premium boot or reboot issues, along with loader.stages.log and nenyoo.log when available. List the fixes you already tried and whether they changed anything. If Discord rejects a large file, compress the relevant logs into a ZIP.

  4. 4
    Follow up in the same report

    Reply to staff questions in the same post. Add new logs after a retest and mention what changed. If you cannot access #bugs, use Support to open a ticket.
