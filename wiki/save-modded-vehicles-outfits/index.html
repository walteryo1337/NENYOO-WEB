Using the menu

Save and import GTA V vehicle and outfit presets

Find the local Vehicles and Outfits folders, import community files, and save your own presets with the menu.

Updated November 13, 2026

Vehicle and outfit presets are local files. Browse community vehicles, modded builds and outfits, preview a creation, then download its original preset file. Saving a local preset does not itself add a purchased vehicle to a GTA Online garage.

The Red Asbo preset page includes the original TXT file, additional preview and import steps. Use the community showcase to compare more selected builds and outfits.

Preset folders

Vehicle presets
%LOCALAPPDATA%\Nenyoo\Plus\Vehicles\
Outfit presets
%LOCALAPPDATA%\Nenyoo\Plus\Outfits\

Paste the path into the File Explorer address bar. These paths match the Plus storage layout. In Saved Vehicles, Open Folder opens the directory used by your installed menu. Back up existing presets before replacing files.

Import a community preset

  1. 1
    Download the original file

    Use the download button on the catalog entry. Keep its original extension. If you receive an archive, extract the preset before copying it.

  2. 2
    Copy to the matching folder

    Place vehicle files in Vehicles and outfit files in Outfits. Do not put them in the Lua Scripts folder.

  3. 3
    Open the saved-preset list

    Open Saved Vehicles to spawn a vehicle preset, or Saved Outfits to apply an outfit. Keep Delete Mode off when selecting an outfit you want to apply.

The current saved-vehicle list recognizes .xml, .json, .ini and .txt files. The saved-outfit list also recognizes .cfg. An extension alone does not guarantee a file is valid or that every feature from another menu is supported.

Save your own vehicle

  1. 1
    Enter the vehicle

    Sit in the vehicle you want to save, then open Saved Vehicles.

  2. 2
    Name and save it

    Enter Save As Name, then choose Save Current Vehicle. Use Open Folder to find the saved file.

  3. 3
    Check the saved preset

    Select the saved entry to spawn a copy and check the appearance and attachments you expect.

Save your own outfit

Open Saved Outfits, enter a name in Save Outfit, and press Enter to save the current outfit. Auto Screenshot can save a preview when saving your own character. Select a saved entry to apply it; the Outfits apply settings control model, clothing, head/face and attachments.

If a preset does not load

  • Confirm the file is extracted and in the correct folder. Keep the original extension.
  • For outfits, check the preset character model and the apply settings. Clothing for one model may not fit another.
  • If the menu reports Preset failed to load, collect the exact message and logs using Collect logs and report a bug. Include the preset name and source link so support can identify the file.
