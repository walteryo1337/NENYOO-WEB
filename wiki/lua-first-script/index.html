Your first Lua script

Where scripts go, how to run them, and a working example.

Updated September 23, 2026

Save scripts in
%LOCALAPPDATA%\Nenyoo\Plus\Scripts\User\

Press F10 in game to open the Lua console. A plain script appears in the menu as an on/off toggle:

Scripts/User/heal_me.lua
-- A plain script becomes an on/off toggle. script.on_tick(function() local me = PLAYER.PLAYER_PED_ID() ENTITY.SET_ENTITY_HEALTH(me, 328) end)

Script locations and loading

  • Use Open Scripts Folder in the menu to open your user-script folder. Save your own scripts under Scripts/User/.
  • Scripts/Lib/Global/ contains foundation code and natives; Scripts/Lib/Api/ contains compatibility layers. Do not place user scripts in these library folders or in the built-in Scripts/Ui/ folder.
  • A plain user .lua script can appear as an enable/disable toggle. Add -- @nenyoo-menu to create an expandable script page instead.

Create a script page

Scripts/User/hello_menu.lua
-- @nenyoo-menu local root = menu.my_root() menu.action(root, "Say hi", {}, "Shows a toast", function() util.toast("hi") end)

The marker makes this a native menu-page script. Build its rows with menu.my_root(), menu.list(), menu.action(), and menu.toggle(). Refer to the Lua API for each function’s arguments.

Keep script and render work separate

script.on_tick / util.create_threadGame natives, memory, and entity operations belong on the script thread.
overlay.on_draw / theme draw_menuDrawing belongs on the render thread: draw, text, and directx operations.
Heads up

Do not call game natives from a draw callback or drawing functions from a tick callback. Mixing these contexts can crash the game. Yield with util.yield(ms) or thread.yield(ms), not the WAIT native.

Test, reload, and unload

  • Press F10 to open the Lua console; Esc closes it. Use it to test small snippets.
  • After editing, use Reload All Loaded to reload currently loaded scripts, or the script’s own reload action.
  • Use Unload on a script page to stop that script and release its resources. If a script fails, collect the error and report it with reproduction steps.

Rules of thumb

  • Call natives and touch memory or entities on the script thread. Draw on the render thread.
  • Yield with util.yield(ms), not WAIT.
  • Write new scripts against the engine and foundation layers.
  • For third-party scripts, follow Install and run Stand scripts.
