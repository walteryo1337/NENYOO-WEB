BattlEye required or “Return to Main Menu” when joining Online (Standard)

Load the menu from the game’s main menu, before entering Story Mode or Online.

Updated September 23, 2026

Heads upLoad only from the main menu

Click Load in the loader only while GTA V is at its main menu / landing page, before selecting Story Mode or Online. Do not load the menu after you have already entered the game. The pause menu while playing is not the main menu.

Messages you may see

When joining Online with Standard, you may see “BattlEye is required”, “BattlEye requires an update”, or “Please return to the Main Menu”. If you loaded the menu after entering the game, restart and follow the loading order below.

Restart and load in the correct order

  1. 1
    Close GTA V and start again

    Use the Standard (BattlEye off) setup described in Launch and inject in GTA V.

  2. 2
    Stop at the main menu

    Wait for the landing page where you choose Story Mode or Online. Do not select either mode yet.

  3. 3
    Load the menu now

    Select your product in the loader and click Load while the game is still at the main menu. Wait for the loader’s console to open.

  4. 4
    Enter Story Mode, then join Online

    After loading from the main menu, enter Story Mode and wait for the menu to be ready before joining Online. Standard users can stay in public sessions while they are the host; see BattlEye and sessions.

What does “Waiting for game state [INIT]” mean?

If you loaded at the main menu, enter Story Mode so loading can continue. If you clicked Load after entering Story Mode or Online, restart GTA V and load from the main menu instead.

If the problem continues after following this order, collect your logs and submit a bug report.
