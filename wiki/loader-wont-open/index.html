Troubleshooting

Loader won’t open

Check missing runtimes, your connection, and antivirus blocking the loader.

Updated September 23, 2026

  1. 1
    Use a VPN

    Some internet providers block the connection. That causes the SSL error and makes the loader close immediately.

  2. 2
    Turn off security software

    Disable antivirus, Smart App Control, and reputation-based protection.

  3. 3
    Put the loader in its own folder

    If the loader runs in Task Manager but no window appears, move it into a dedicated folder and open it again.

  4. 4
    Exclude the loader folder in Windows Defender

    Open Windows Security → Virus & threat protection → Manage settings → Exclusions → Add or remove exclusions → Add an exclusion → Folder. Select the dedicated folder containing the loader. If you move it, update the exclusion. If you use another antivirus, add the same folder to its exclusions too. See Microsoft’s exclusion instructions ↗.

  5. 5
    Install the runtimes and restart

    Install both Visual C++ runtimes (x64 and x86) and the DirectX runtime, then restart Windows before trying the loader again. See Crashes on inject for the runtime download links.

  6. 6
    Sync your clock

    Settings → Time & language → Date & time → Sync now.
