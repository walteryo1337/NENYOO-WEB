GTA V Hash Reverse Lookup

Look up known GTA V hashes in hexadecimal or decimal. Inspect database candidates and see whether the returned string hashes back to the requested value.

Search the GTA Discovery database for a known identifier. This is a database lookup, not a mathematical reversal. The result separates a verified source string from a database label that has not been verified.

03 / LOOKUP

Hash Reverse

Find known identifiers in the GTA Discovery database. A hash can have multiple original strings.

Source: GTA Discovery API ↗

How to use this tool

  1. Paste a hexadecimal value beginning with 0x, an unsigned decimal, or a signed decimal.
  2. Select Reverse Lookup. The database is fetched only when you run a lookup.
  3. Check the result label. Verified source string means the candidate hashes back to the requested 32-bit number.

Worked examples

Look up a vehicle model

Input: 0xB779A091 or 3078201489 or -1216765807

Each input searches the same u32 key: 3078201489

The signed value is wrapped to 32 bits. If the database contains the matching candidate adder, its hash can be verified locally.

Verify a weapon candidate

Input: 0x1B06D571

weapon_pistol hashes to 453432689

A database entry may use the shorter label pistol. The verifier also checks common domain prefixes rather than assuming the label is the original string.

What the result means

  • No matching hash means the supplied database has no entry; it does not mean the identifier is invalid.
  • An unverified identifier is a useful database label, not proof of the exact original string. Collisions may exist.
  • Reverse lookup requires a network connection to the GTA Discovery dataset on jsDelivr. The local JOAAT generator works independently of that download.
