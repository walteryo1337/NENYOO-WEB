How to use this tool

  1. Enter Value A and Value B. Decimal, 0x hexadecimal and a leading + or - sign are accepted.
  2. Choose Add or Subtract. Fractions and malformed numbers show an input error.
  3. Copy the exact hexadecimal or decimal result. Use u32 only when your destination expects a wrapped 32-bit value.

Worked examples

Add an offset

Input: 0x1F00 + 0x10

Hex: 0x1F10
Decimal: 7952
u32: 0x1F10 (7952)

Hexadecimal 0x10 is decimal 16. Both input fields can use either base.

Understand wrapping

Input: 0 - 1

Hex: -0x1
Decimal: -1
u32: 0xFFFFFFFF (4294967295)

The exact result remains negative. Only the explicitly labelled u32 result wraps modulo 2^32.

Keep a large integer precise

Input: 9007199254740993 + 1

Decimal: 9007199254740994

The calculator uses integer arithmetic rather than floating-point numbers, so integers above JavaScript’s ordinary safe-number range are preserved.

What the result means

  • This tool calculates numbers; it does not inspect or change game memory.
  • Input is limited to integers. Decimal fractions, multiplication and division are not supported.
  • Unsigned wrapping is a representation choice. It does not validate an address or offset for a particular game version.
