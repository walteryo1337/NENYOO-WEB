GTA V JOAAT Hash Generator

Generate GTA V JOAAT hashes from model and identifier names. Compare hexadecimal, unsigned decimal and signed decimal results with worked examples.

Turn a GTA identifier into its 32-bit Jenkins one-at-a-time hash. This calculator lowercases the input, then shows three representations of the same bits. Use it when a script or data file expects a numeric model or weapon identifier.

How to use this tool

  1. Enter an identifier such as adder or weapon_pistol. Do not add quotation marks.
  2. Copy hexadecimal, unsigned u32 or signed i32 to match the format expected by your script.
  3. Use reverse lookup when you already have a number and want to search the known-identifier database.

Worked examples

Vehicle model

Input: adder

Hex: 0xB779A091
Unsigned: 3078201489
Signed: -1216765807

ADDER produces the same result because input is lowercased. Signed decimal is negative here because bit 31 is set.

Weapon identifier

Input: weapon_pistol

Hex: 0x1B06D571
Unsigned: 453432689
Signed: 453432689

All three values identify the same 32-bit hash. A missing prefix, extra space or different identifier changes the input.

What the result means

  • Hashing does not prove that an identifier exists in your game build.
  • Hashes are not unique: different strings can produce the same value. They are not encryption and cannot be reliably reversed.
  • Use ASCII GTA identifiers for matching the game and Lua examples. Spaces are kept, so remove accidental whitespace.
