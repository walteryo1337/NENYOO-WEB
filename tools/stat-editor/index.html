GTA V stat editor

Find a stat, add it to your export, and edit its value. Copy the JSON or download your file.

How to use this tool

  1. Search for PSTAT_INT0 or another name, then select an entry to add it to Your export.
  2. Choose an item in your draft and edit its value. Invalid numeric and boolean values must be fixed before export.
  3. Review the JSON preview, then copy it or download gta-stats-edited.json. Save it before leaving the page.

Worked examples

Export one numeric entry

Input: Select PSTAT_INT0 and enter 1

{
  "stats": {
    "PSTAT_INT0": 1
  }
}

The output contains only selected entries. This demonstrates the file shape; it is not a recommendation to apply a stat value in game.

Preserve types

Input: Number → 42; Boolean → true; Text → your text

Numbers remain JSON numbers, booleans remain true/false, and text is JSON-escaped.

Types come from the supplied example file. A name containing BOOL can still have a numeric example value; the editor does not infer game storage types from names.

What the result means

  • Edits are kept only in page memory and are cleared by leaving or reloading. Download or copy your work first.
  • This page does not write to GTA V or an online account. Confirm any consuming tool’s format and compatibility separately.
  • The example dataset is not a live game-build compatibility list. Numeric values must be finite and integer values must stay within the safe integer range.
